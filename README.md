# 《弹弹识字》V1

> **产品定位**：4～6岁儿童物理弹球 + 识字启蒙游戏  
> **运行形态**：**独立 H5 网页 (手机/平板横屏、微信内置浏览器、PC 端通用)**  
> **渲染架构**：**Pixi.js v7 (WebGL 硬件加速 / 批量自动合批渲染) + TypeScript + Vite**  
> **核心性能**：**Gzip 首包仅 152 KB，0.2 秒瞬间秒开，锁死 60/120 FPS，零垃圾回收卡顿**

## 🚀 启动与开发指南

### 1. 一键运行（开发者与测试）
- **Windows 用户**：直接双击运行根目录下的 [`start_game.bat`](./start_game.bat)。
- **命令行启动**：
  ```bash
  npm run dev       # 启动 Vite 本地开发服务器 (带热重载 HMR，端口 8088)
  npm run build     # 1.5 秒极速产出可部署的 dist/ 生产包
  npm run preview   # 本地预览构建产物
  ```

### 2. 生产部署（上线）
项目已一键编译出生产包目录 [`dist/`](./dist/)：
- 直接将 `dist/` 文件夹上传到任何静态服务器（Nginx、阿里云 OSS、腾讯云 COS、GitHub Pages、Vercel），直接对外提供服务，零配置开箱即用。

## 📱 移动端与全平台专属特性

1. **双模态自适应架构 (Dual-Mode Viewport)**：
   - **手机原生竖屏**：自动进入专属纵向长屏模式，动态匹配屏幕物理比例，100% 杜绝拉伸变形，小球与文字恒定保持纯正圆形。
   - **平板/PC/横屏**：自动进入 16:9 经典高清宽屏模式。
   - **一键自由旋转**：无需配置手机系统重力感应，界面内一键即可在横屏与竖屏间自由无缝切换。
2. **三段式极简 HUD**：左侧关卡徽标、中间得分连击、右侧圆形微按键（静音与暂停），非核心操作收纳于暂停弹窗，手机全屏无遮挡。
3. **加长瞄准引导线**：大幅延伸至 880px，支持侧壁真实镜面反弹预测，指引清晰。
4. **超清 3D 水晶玻璃球质感**：带高曲率高光、菲涅尔边缘泛光、透光焦散与内嵌悬浮汉字。
5. **iOS / Safari Web Audio 解锁**：首触预热静音通道，无独立录音时无缝触发标准普通话语音合成兜底。

## 🎮 游戏核心玩法与系统

1. **5 大分级词库体系（共 300 核心汉字）**：
   - **第 1 级**：启蒙基础（数词、自然天地、身体动作与亲人）
   - **第 2 级**：探索世界（代词、四季气候、常见动物与生活色彩）
   - **第 3 级**：认知表达（家庭成员、身体部位、疑问词与特征反义词）
   - **第 4 级**：逻辑空间（方位定向、动作指令、身体感受与逻辑连接）
   - **第 5 级**：丰富表达（量词度量、五味感官、形态细节与事理法则）
2. **艾宾浩斯遗忘曲线复习引擎**：根据记忆遗忘规律（间隔 N-1, N-2, N-5, N-7），在关卡中智能引入新词与高权重易错字复习。
3. **全消通关机制**：单关消灭全部目标汉字球即可通关并保存星级与进度。
4. **小怪兽图鉴系统**：5 只原创卡通小怪兽随关卡与识字进度动态解锁。
5. **家长防误触门禁与学习看板**：内置大写乘法验证题，通过后可查看今日识字曝光、命中率及艾宾浩斯记忆留存率统计。
